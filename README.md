# 🛒 Shopping Menu App

A simple and interactive web application designed to help users manage their shopping list efficiently. Built with HTML, CSS, and JavaScript.

## 🚀 Live Demo

Check out the live deployed application here:
👉 **[View Live Project](https://shopping-menu-6d4dob390-glens-projects-977495b6.vercel.app/)**

---

## ✨ Features

- **Add Items:** Easily add new items to your shopping list.
- **Mark as Purchased:** Toggle items to track what you've already bought.
- **Delete Items:** Remove items you no longer need.
- **Responsive Design:** Works smoothly across desktop and mobile browsers.

---

## 🛠️ Built With

- **HTML5** - Structure and semantic content
- **CSS3** - Custom styling and layout
- **JavaScript (ES6+)** - Interactivity and dynamic DOM manipulation
